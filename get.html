Nothing happened? Download Pane Relay for Mac (macOS 14 or later).

Three steps on this Mac

  1. Open PaneRelay.dmg in Downloads and drag Pane Relay to Applications.
  2. Open Pane Relay. It lives in the menu bar and shows a pairing code.
  3. Point the iPhone camera at the code. Pane opens and pairs the Mac.

Controlling this Mac from Pane right now?

The code is on the screen you are holding, so the camera cannot see it. Click Copy pairing code in Pane Relay instead. Then leave the session in Pane, open this Mac’s details and tap Paste code. Universal Clipboard carries the code to the iPhone when Handoff is on.
