Pane: Remote Desktop for Mac · jan.jiran@understudios.org

1. Turn on Screen Sharing on your Mac

Pane talks to the Screen Sharing service built into macOS, so there is nothing to install on the Mac.

  1. Open System Settings › General › Sharing.
  2. Turn on Screen Sharing. (If Remote Management is on, turn it off first; the two cannot run together.)
  3. Click the ⓘ next to Screen Sharing and choose who may connect: All users or Only these users.
  4. Optional: under Computer Settings, enable VNC viewers may control screen with password only if you want to sign in with a separate VNC password instead of your Mac account. Pane works with both.
  5. Note the Mac’s name shown under General › About (for example Studio). On your local network it is reachable as studio.local.

In Pane, tap Add Mac. Macs with Screen Sharing on usually appear by name within a few seconds; otherwise type the .local name or IP address. When asked, sign in with your Mac user name and password (the same ones you use at the login screen).

Let the Mac wake up

So that Pane can wake a sleeping Mac, enable Wake for network access in System Settings › Battery › Options (laptops) or Energy (desktops). Keep the Mac on Ethernet or the same Wi-Fi network; waking works on the local network only.

2. Connect from anywhere with Tailscale

Tailscale gives each of your devices a private, stable address that works from any network, with no port forwarding.

  1. Install Tailscale on the Mac (tailscale.com/download) and on your iPhone or iPad (App Store), and sign in to the same account on both.
  2. In the Tailscale admin console, make sure MagicDNS is on. Your Mac is then reachable by its machine name, for example studio, or by its 100.x.y.z address.
  3. In Pane, add a Mac and enter that name or address. Port stays 5900.
  4. Make sure the Tailscale app is connected on your iPhone or iPad before you connect. Tailscale on the Mac must be running too; set it to start at login.

Tailscale encrypts the whole connection end to end, so this is also the recommended way to use Pane on public Wi-Fi.

3. Common errors

What you seeWhat it usually means
Connection refusedScreen Sharing is off on the Mac, or the Mac’s firewall blocks it. Check System Settings › General › Sharing, then System Settings › Network › Firewall.
Timed out / Host not foundThe Mac is asleep, on a different network, or the name does not resolve. Try the IP address, check that both devices are on the same Wi-Fi, or connect Tailscale on both.
Authentication failedUse your Mac user name (short name or full name) and login password. If you enabled a VNC password on the Mac, leave the user name empty and enter that password instead.
Nothing shows up when adding a MacPane needs the Local Network permission to discover Macs. Allow it in Settings › Privacy & Security › Local Network › Pane, then pull to refresh.
Black screen or only the login windowThe Mac is locked or another user is logged in. Sign in on the remote login window; macOS may ask whether to share the current display or open a virtual display.
Wake does nothingWake for network access is off, the Mac is on a different network, or it is fully shut down (wake only works from sleep).
Keyboard shortcuts go to the iPadSome system shortcuts (⌘H, ⌘Tab, ⌘Space) are reserved by iPadOS. Use the on-screen modifier bar in Pane to send them to the Mac.
Choppy or slowMove closer to the Wi-Fi router, prefer 5 GHz, or lower the quality setting in the session panel. Over Tailscale, a direct connection is much faster than a relayed one; check tailscale status on the Mac.

4. Still stuck?

Email jan.jiran@understudios.org with your iPhone or iPad model, iOS version, macOS version and the exact error text. We read everything and usually answer within a few days.
